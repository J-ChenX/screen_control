## 被替代或否决的路线

- `nix` 的 Wayland/Portal 路线已被 Xorg 替代；不再作为当前方案或需求保留。
- NAS 独立页面/API、自建可恢复回收站、非 NAS 目录受限、按来源设备动态改变文件权限等旧方案均已被统一文件入口替代。
- 具体远控、传输协议和运行时属于第二阶段选型，不将当前候选误写为既定方案。

已实施的桌面改动、验证结果和备份路径只在 [ENVIRONMENT_AUDIT.md §2–§3](ENVIRONMENT_AUDIT.md) 维护。
