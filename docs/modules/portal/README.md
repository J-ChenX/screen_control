# 门户 — 统一网页

**最后更新：** 2026-09-04
**状态：** 🔄 UI/UX 基线与 G0 实机设备/桌面/文件接入完成；身份、统一文件数据面、事件流和生产安全边界仍为 `[计划中]`

## 一句话职责

提供唯一桌面网页入口，编排三台设备、控屏、文件和剪贴板视图，但不复制身份、选路或领域规则。

## 信息架构

| 路由 | 内容 | 领域来源 |
|---|---|---|
| `/login` | 密码登录、限速反馈 | `identity` |
| `/` | 三设备卡片及 host/desktop/files/clipboard 分项状态 | `control-plane` |
| `/devices/:id/desktop` | 仅桌面启动、路径与锁屏三态 | `remote-desktop` |
| `/devices/:id/files/*` | 系统根/卷根、搜索、批量、传输 | `file-fabric` |
| `/settings/security` | 改密、退出当前会话 | `identity` |

## 交互规则

- 界面只展示服务端领域状态；不从原始字段自行推断在线、路径或权限。
- 禁止远程终端、命令输入、跨设备移动、回收站恢复/清空和 Mesh 管理入口。
- 危险操作使用领域返回的标准确认模型；覆盖需展示陈旧前置条件，永久删除必须第二次确认。
- 桌面视图离开、标签页关闭或网络断开只调用普通结束，保持目标原锁态。
- 所有错误显示“发生了什么、是否执行、如何恢复”；结果未知不得用成功提示。

## 视觉与可用性基线

- 采用固定主导航与内容工作区：设备总览是默认入口，安全设置独立呈现；桌面和文件页保留清晰的设备上下文与返回路径。
- 状态颜色只作辅助，所有 `online/connecting/offline/error` 与 `ready/degraded/unavailable/unknown` 状态同时提供文字；主机、桌面、文件、剪贴板必须分项显示。
- 使用冷灰背景、白色任务面板和低饱和绿色主操作色；黄色表示降级或待确认，红色仅表示确定失败。未知结果不得套用成功或失败样式。
- 桌面浏览器以三列设备卡片为基线，窄窗口逐级降为两列和单列；保留键盘焦点、语义化标题/导航，并尊重 `prefers-reduced-motion`。
- G0 实机桥接可显式标注“G0 实机”，设备、桌面和文件状态必须来自后端；未接入的身份和锁屏能力继续保持禁用或明确标为“预览”，不得用模拟成功冒充领域结果。

## 当前代码状态

- `web/src/app/App.tsx`：响应式 AppShell、登录反馈、设备筛选、桌面会话预览、文件搜索/多选、危险操作确认与安全设置流程。
- `web/src/app/ErrorBoundary.tsx`：应用级错误边界，明确说明未自动重试任何设备或文件操作。
- `web/src/app/model.ts`：文档路由解析、状态类型和后端不可用时的失败即拒绝登记清单；运行时由 `/api/v1/control/snapshot` 的权威快照替换。
- `web/src/api/client.ts`：G0 门户 API 客户端，不接收或保存 MeshCentral 凭据。
- `web/src/features/desktop/MeshDesktop.tsx`：一次性桌面会话和同源 WS 中继客户端；仅用于本机 G0，不能替代生产独立源站门。
- `web/src/features/files/MeshFiles.tsx`：独立文件凭据的一次性协议 5 会话，可执行真实列表、上传、下载、新建、重命名和二次确认永久删除；不等同于生产文件数据面。
- `web/src/styles.css`：视觉令牌、状态样式、桌面/窄窗口布局、键盘焦点与减少动态效果规则。

以上完成可交互的 UI/UX 与 G0 实机通道，但不代表 `PC-07`–`PC-09` 完成；真实登录、正式领域客户端、事件重同步以及生产远控/文件操作仍受各工作包前置与验收约束。
