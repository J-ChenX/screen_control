# 远程桌面 — 无人值守控屏

**最后更新：** 2026-09-04
**状态：** 🔄 三机 G0 实机桥接已可用；三设备状态、一次性桌面会话和同源 WS 中继已接入，完整门证据与生产实现尚未完成

## 一句话职责

隔离仅桌面远控内核并管理启动、控制、结束、撤销及“锁屏并退出”的可验证生命周期。

## G0 进入条件

全面实现前必须通过[远控任务的唯一 G0 四门清单](../../tasks/private-web-remote-remote/_INDEX.md)：三平台登录前/安全桌面、仅限 Tailscale 失败即拒绝、仅桌面、独立源站 + 无 URL 启动交换。任一项需长期分叉、仅使用 TURN 或不能强制，则淘汰 MeshCentral 并回到架构选型；六条完整旅程、输入/画面与 A07 统计属于 G3。

当前尖峰入口为 `deploy/spike/meshcentral/`：固定依赖、受限容器、三平台代理、桌面专用账号以及 `internal/g0bridge/` 的门户桥接已经能完成真实设备枚举和桌面画面/输入。门户同时提供回环地址与 Tailscale 私有网络开发入口，其他两台登记电脑已反向验证页面/API 可达。浏览器只取得一次性 `dsk_*` 定位符，MeshCentral cookie 留在后端内存。它仍不等于 G0 全部通过；仅限 Tailscale 对抗证据、登录前/安全桌面矩阵、独立源站与启动交换负测仍须按任务清单留证。

## 核心流程

| 场景 | 流程 |
|---|---|
| 启动 | 会话/目标 → 独占远控租约 → `PathDecision` → 3 s 内返回操作 → 独立源站内存交换 desktop-launch → iframe/WS 双重校验 |
| 控制 | 仅画面/键鼠 → 路径和租约持续校验 → 序列化输入；不含音频/剪贴板 |
| 普通结束 | 停发输入 → 关闭 WS/WebRTC → 释放租约；不改变目标锁态 |
| 异常/撤销 | 立即停发且不重放 → 关闭/重协商 → 到期强制终止；不自动锁屏 |
| 锁屏并退出 | 一次性操作摘要 → 平台固定锁屏 → 操作报告 Confirmed/Failed/Unknown；三种结果都结束控制，后两种明确提示目标锁态未知及本地处理动作 |

## 业务规则

- 三台来源到另外两台共 6 条有向旅程；首版每目标最多一个操作者、单主屏。
- Ubuntu GDM/Xorg、锁屏，Windows 登录/锁屏/UAC 必须画面和键鼠有效。
- 4K 目标最高 `1920×1080`；`nix` 最高 `1728×1080`；保比例、不裁剪、不拉伸、无音轨。
- 常规结束、关页、断网或异常均保持原锁态；只有显式按钮可锁屏。
- `PathPolicy` 给出路径，远控只执行并验证实际候选项配对，不复制路由规则。
- `desktopSessionId` 只是定位符；每个 HTTP、iframe、WS、输入、结束、锁屏和证据入口都复核父会话、来源、目标、租约代次、作用域、撤销代次与到期。
- “锁屏并退出”选择失败仍退出，是为了不在锁态未知时保留高权限控制通道；用户可从门户读取状态后建立新会话重试，系统不得把 Failed/Unknown 显示为已锁。

## 对外契约

字段、路由、操作、错误、IDOR 绑定与截止时间 **只**由[协议契约 §2–§5、§8](../../appendix/protocol-contracts.md)定义。本表仅索引所有权。

| 接口组 | 权威条目 | 消费者 |
|---|---|---|
| 启动/读取 | 远程桌面 v1 `desktops` | 门户 |
| 结束 | 远程桌面 v1 `:end` 操作 | 门户、撤销器 |
| 锁屏退出 | 远程桌面 v1 `:lock-exit` 操作 | 门户 |
| 诊断 | 远程桌面 v1 `evidence` | 运维模块 |

详细组件与状态机见 [架构](architecture.md)，隔离威胁见 [安全](security.md)。
