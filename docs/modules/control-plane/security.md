# Control Plane — 安全

**最后更新：** 2026-09-03

## 权限与不变量

| 操作 | 授权 |
|---|---|
| 状态与路径事实上报 | 目标设备的有效独立代理身份；上报设备 ID 必须等于 peer 登记；唯一写入口为 `StatusIngestor` |
| 读取/订阅 | 有效浏览器会话且来源节点仍登记 |
| 获取/续租 | 有效会话、允许的固定操作枚举、目标登记、父代次有效 |
| 读取路径决策 | 有效会话或领域服务身份；只传 flow/source/target，不接受调用方事实 |

- 租约不是领域授权替代品；remote/file 在消费时再次校验主体、scope、目标与代次。
- 不接受任意地址、URL、命令或自由文本操作；操作摘要标准化后参与幂等键绑定。
- 路径证据未知、冲突或陈旧时只能降级为 `offline`/显式不可用，不能猜测；任意消费者试图提交 `facts/now/path label` 按 `INVALID_ARGUMENT` 拒绝并记安全事件。
- 事件对门户隐藏原始 IP、令牌和诊断秘密；完整网络证据只写权限受限运维存储。
