# HTTPS 网关入口

状态：可选网关实现。默认关闭，配置与测试完成不代表公网已上线。

浏览器 → HTTPS 443 网关/反向隧道 → **127.0.0.1:8791** → 受认证的 Portal/API/WebSocket → 原 MeshCentral/Tailscale 网络。

此入口不依赖访问端 Tailscale 私网 DNS 或 VPN 的 DIRECT 规则。要求浏览器所在网络允许访问选定域名的 HTTPS 与 WebSocket，并且 echova 能连接隧道服务。受控端仍使用现有 Tailscale/MeshAgent 链路；尚未实现受控端的独立公网出站中继。不能保证任意网络下始终在线。

## 上线步骤

1. 准备一个实际可用的域名及 HTTPS 反向隧道。不要把旧的 8790、8444、4443 或 MeshCentral 管理页面映射到公网。
2. 在 echova 运行（将域名替换为实际域名）：

   ```bash
   python3 deploy/gateway/prepare.py --origin https://remote.your-domain.com
   ```

   创建 `~/.config/screen-control/gateway/`，包含权限为 0600 的凭据哈希、三台设备的独立随机访问密钥、环境配置和 Cloudflare 命名隧道示例。命令不打印密钥，不替换已有目录，也不修改网络。
3. `make install-suite` 安装新服务。服务读取可选的 `%h/.config/screen-control/gateway/gateway.env`；如使用自定义目录，需自行配置 systemd EnvironmentFile。网关只能监听回环地址，原私有入口仍可使用。
4. 按 `cloudflared.yml.example` 创建命名隧道和 DNS 记录，在 echova 运行连接器，保持 Host 为公网域名，并转发 WebSocket。TLS 必须由公网网关终止。若使用自建 VPS，需建立到回环地址的加密反向隧道，不能直接把 8791 绑定公网。
5. 将各 `.key` 文件通过现有受信 SSH 交给对应设备的用户；在浏览器登录页输入一次。密钥不得写入 URL、聊天、仓库、日志或网页 Storage。
6. 从代理网络和手机热点测试：未登录访问 API 返回 401；登录后身份与签发设备对应；控屏、文件、退出和网络切换正常。必须验证实际长连接，不能只测首页。

## 身份与撤销

- 网关使用每设备 256-bit 随机访问密钥，服务器只读取 SHA-256 哈希；**不是用户自选密码**。
- 密钥代表管理员授予某设备标签的权限，持有者可在其他浏览器使用；这不是硬件绑定或设备证明。若必须强制只允许三台物理电脑，需要进一步引入设备证书或硬件密钥。
- 登录使用 Secure、HttpOnly、SameSite=Strict 的 `__Host-` Cookie，8 小时绝对到期。登录令牌只保存在服务器内存；服务重启撤销所有登录。
- 退出立即撤销该登录并取消其活动桌面/文件通道。同一设备的另一登录也不能接管或结束该会话。
- 删除/轮换凭据哈希并重启服务可撤销某设备密钥与所有旧会话。单纯退出不会撤销长期访问密钥。
- 禁止信任 X-Forwarded-For、Tailscale-* 或客户端自报设备身份。网关通过单独的内部认证上下文传递身份。
- 登录尝试全局限制为每分钟 30 次；高熵密钥防猜测。公网入口仍建议配置边缘限流，应用限流不提供抗 DDoS 保证。

## 网络恢复与限制

- API 请求 12 秒超时，401 引导重新登录；状态轮询不重叠，网络恢复时立即刷新。
- 桌面中断后按 1、2、4、8、16、30 秒重试，上限 30 秒；手动结束或离开页面取消重试。每次创建新会话，不重放旧键鼠输入。
- 中继每 20 秒发 WebSocket Ping，10 秒超时检测断链。这不是 15 秒恢复保证。
- 文件中断明确标记失败，清除下载聚合和进度；不自动重放上传、删除、重命名等操作。上传可能在目标保留不完整文件，需要检查后重传；断点续传尚未实现。

## 回滚

先停用公网隧道，再移走 `gateway.env` 并重启 `screen-control-suite.service`。原 Tailscale 入口保留。密钥目录和隧道配置应按私密资料备份。

```bash
make test
make verify
make build
python3 tests/browser/gateway_smoke.py
```

浏览器测试启动临时回环地址 HTTPS 代理和独立网关实例，使用临时密钥验证真实登录、退出与设备识别；桌面协议在浏览器测试中为模拟，验证自动重连和手动停止，不操作远端电脑。Go 集成测试另行验证真实 TLS/WebSocket 转发和退出撤销。测试不会创建公网入口，结束时删除临时密钥并停止测试进程。
